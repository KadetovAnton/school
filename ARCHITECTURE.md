# Архітектура: домашня навчальна платформа (перший модуль — англійська для Ані, 7 клас)

> Мета: закрити прогалини з 5–6 класу, вийти на рівень 7 класу і йти далі.
> Головний принцип: **зрозуміло і цікаво, а не каторга.** Помилка — це сигнал «закріпимо ще разок», а не покарання.

Сайт: https://kadetovanton.github.io/school/ (GitHub Pages, репозиторій `KadetovAnton/school`)
Пристрої учня: iPhone (Safari) і MacBook Pro 2015 (macOS Monterey, Safari 15–16). Усе має працювати на обох.

---

## 0. Бачення: платформа для обох дітей і різних предметів

- **Діти:** Аня (7 клас) і Артем (2 клас). У кожного свій профіль: клас, прогрес, інтереси, нагороди, свій «вигляд» (Аня — кабінет підлітка, Артем — яскравий ігровий світ: коротко 5–10 хв, озвучені завдання, картинки, перетягування, спочатку з татом поруч).
- **Мета:** не зубріння, а розуміння і цікавість; показати, навіщо кожен предмет і як подивитися на світ з його точки зору.
- **Спільне ядро:** рушій, мотивація (зірки, значки, серії, нагороди), звіти для тата.
- **Два типи предметних модулів:**
  1. **Предмети-навички** (англійська, техніка математики/алгебри, правопис): практика до засвоєння, цикл «помилка → 2–3 схожі завдання», повторення (розділи 2–6).
  2. **Предмети-розуміння** (фізика, хімія, біологія, географія; для Артема — «Я досліджую світ»): формат «від явища до закону»: загадка з життя → «як думаєш?» → інтерактивна модель → пояснення простими словами → формула як короткий запис → «де це в житті» → досвід удома → перевірка розуміння («поясни, що буде, якщо…»).
- **«Навіщо цей предмет»:** коротка вступна серія на початку кожного предмета.
- **Порядок:** 1) англійська для Ані (доводимо рушій); 2) пілот предмета для Артема (з того, що найважче; уточнити в тата, а також його інтереси); 3) розширення.

## 1. Принципи (на чому стоїть система)

Взято з перевірених практик (Khan Academy, Duolingo, дослідження когнітивної науки про навчання):

1. **Навчання до засвоєння.** Не йдемо далі, поки навичка не засвоєна (Khan Academy).
2. **Пригадування замість перечитування.** Учень сам згадує й пише відповідь, а не впізнає готову.
3. **Інтервальні повторення.** Тема повертається через 1 → 3 → 7 → 14 днів.
4. **Перемішування тем.** У розминці навички змішані, щоб вчитися їх розрізняти (Simple чи Continuous?).
5. **Помилки повертаються наприкінці сесії**, а не одразу ж тим самим питанням (Duolingo).
6. **Розібрані приклади.** Спершу «дивись, як я думаю», потім сама.
7. **Короткі сесії.** Ціль 15 хвилин на день, краще щодня потроху.

## 2. Зміст: карта мікронавичок

Кожна тема ділиться на дрібні **мікронавички**. Помилка завжди прив'язана до конкретної навички, тож видно точно, де дірка.

Приклад, Present Simple:
| id | Мікронавичка |
|---|---|
| ps.base | I / you / we / they: дієслово без змін |
| ps.s | he / she / it: + s |
| ps.es | -s, -sh, -ch, -x, -o → + es |
| ps.ies | приголосна + y → ies (study → studies) |
| ps.has | have → has |
| ps.adv | місце always / usually / never |
| ps.neg | don't / doesn't + дієслово |
| ps.q | питання з Do / Does |

Кожна мікронавичка має:
- **пояснення** (коротко, українською, з прикладом і озвучкою);
- **розібраний приклад** («дивись, як я думаю», крок за кроком);
- **альтернативне пояснення**, тільки для складних навичок (-es/-ies, do/does, was/were, Present Perfect…);
- **банк завдань**: 8–15 різних речень у різних форматах;
- **типові помилки** з поясненням саме цієї помилки (`goed → went`, `studys → studies`).

### Шлях навчання (25 уроків; звірено з практикумом Павліченко і планами 7 кл. НУШ)
1. **Фундамент (5–6 кл.):** to be → Present Simple (2 уроки) → Present Continuous → Simple чи Continuous
2. **Опис світу (5–6 кл.):** have got → There is / are → прийменники in / on / at → множина, some / any → much / many → артиклі → чиє це ('s, this / these) → займенники
3. **Минуле (6 кл.):** Past Simple (-ed, was / were) → 30 неправильних дієслів → питання й заперечення
4. **Майбутнє, порівняння, правила:** will / going to → ступені порівняння → can / must → пропозиції й запрошення
5. **7 клас (НУШ):** розділові запитання → Past Continuous → Present Perfect → Present Perfect Continuous + PP чи PS → Past Perfect

Порядок тем 7 класу та словник підлаштовуються під шкільний підручник (коли буде фото змісту).

## 3. Формати завдань

| Формат | Для чого | Частка |
|---|---|---|
| Вписати слово | основна практика: пригадування | висока |
| Скласти речення зі слів | порядок слів | середня |
| Диктант: чую → пишу | слух + правопис (озвучка браузера) | середня |
| Знайди помилку в реченні | розуміння правила | середня |
| Вибір із 2–3 варіантів | лише знайомство з новою темою | низька |
| Читання тексту + питання | розуміння тексту | у кінці теми |
| Картки слів | словник | щодня |

**Перевірка відповідей:**
- без різниці великі/малі літери, апострофи, крапки, зайві пробіли;
- кілька правильних варіантів (`don't like` = `do not like`);
- **описка ≠ граматична помилка:** якщо різниця в 1 літеру і це не відома типова помилка, показуємо «майже, перевір написання» і даємо виправити один раз без штрафу.

## 4. Цикл «помилка → розуміння» (ядро системи)

```
Завдання
  ├─ правильно (без підказки) → навичка +1
  └─ помилка
       1. Пояснення саме цієї помилки (не просто «неправильно»)
       2. Розібраний приклад: «дивись, як я думаю»
       3. Серія закріплення: 2–3 НОВІ речення на ту саму навичку,
          з кожним разом підказок менше
            ├─ 2 з 3 правильно → «Зрозуміла! 💪» → далі
            └─ ні → альтернативне пояснення (інша аналогія/схема) → ще серія
                    └─ знову ні → позначка «розібрати з татом / репетитором»,
                       йдемо далі (не мучимо)
  Наприкінці сесії: ще раз 1 завдання на кожну навичку, де була помилка.
```

Мова інтерфейсу м'яка: «Закріпимо ще разок», «Майже!», «Розберімо разом», без «Помилка!», «Неправильно!».

Підказки (2–3 рівні): натяк → правило → (відповідь показуємо лише після спроби або «Не знаю»).
Підказка не карається сильно: правильно з підказкою = 0,5 бала.

## 5. Рівні засвоєння

| Для Ані | Внутрішньо | Як потрапити |
|---|---|---|
| 🌱 Вчу | не почато / спробувала | почала навичку |
| 🌿 Знаю | впевнено | 3 правильно поспіль без підказок |
| 🌳 Засвоєно | засвоєно | правильно при повторенні **в інший день** |

Засвоєна навичка може повернутися в «Знаю», якщо при повторенні помилка. Це нормально і не звучить як невдача.

## 6. Повторення

- **Розклад:** після «Знаю» навичка повертається через 1 → 3 → 7 → 14 днів. Помилка → інтервал скидається на 1 день.
- **Щоденна «Розминка» (5 хв):** перемішані завдання з навичок, яким пора повторитися, плюс 5–10 карток слів.
- **«Мої помилки»:** колекція речень, де помилялась. Можна пройти окремо.
- **Контрольна точка** після кожного етапу: коротка повторна діагностика, щоб бачити ріст у відсотках.

### Трек слів (окремо від граматики)
Картки за системою коробок: знаю → коробка вище → повертається рідше; не знаю → коробка 1 → завтра знову.
Слова за темами (розпорядок дня, школа, сім'я, їжа, хобі, місто, подорожі…), потім за підручником.
Формати: англ → укр, укр → англ (вписати), слухаю → пишу.

## 7. Цікаво, а не каторга (мотивація)

**Що робимо:**
1. **Короткий, зрозумілий день.** На головній одна велика кнопка «Заняття на сьогодні (~15 хв)»: розминка → новий крок уроку → помилки. Не треба думати, що робити.
2. **Видимий прогрес.** Мапа шляху з етапами, зірки за уроки, рівні 🌱🌿🌳, відсотки на контрольних точках. Дитина бачить, що росте.
3. **Серія днів з поблажкою.** 🔥 днів поспіль; 1 «заморозка» на тиждень, тож пропущений день не обнуляє все.
4. **Досягнення (значки):** «Перший урок», «7 днів поспіль», «10 помилок виправлено», «Майстер -es», «100 слів» тощо. Значки й за старанність, а не лише за ідеальність.
5. **Тижнева нагорода в реальному житті.** Зірки за тиждень → нагорода, про яку домовляються тато й Аня (заздалегідь, видно на сторінці: «до нагороди ще 12 ⭐»).
6. **Персоналізація.** Речення в завданнях про те, що їй цікаво (тварини, музика, друзі тощо, уточнити в Ані), з її ім'ям. Розблоковувані теми оформлення й аватарки за зірки.
7. **Міні-ігри для різноманітності:** «Знайди помилку», «Пари слів на час», «Збери речення», «Диктант-челендж». Раз на кілька днів «скарбничка-сюрприз» з бонусним завданням.
8. **Святкуємо зусилля:** «Ти виправила 5 помилок — це і є навчання!» Анімація-конфеті на кінець уроку.
9. **Вибір.** Після обов'язкової розминки можна обрати, що робити далі: урок, гра, слова.
10. **Вільний режим шкільних тем.** Якщо в школі контрольна з теми, яка за планом ще закрита, її можна відкрити. Замки для порядку, не як перешкода.

**Чого НЕ робимо:**
- «життів», які закінчуються через помилки (як сердечка в Duolingo): помилка ніколи не блокує навчання;
- рейтингів і порівняння з іншими;
- нагадувань із почуттям провини;
- довгих уроків: один крок ≤ 10 хв;
- реклами, сторонніх посилань, збору особистих даних.

## 9. Технічна архітектура

```
school/
├─ index.html                 оболонка: підключає рушій; тут APP_VER (версія для скидання кешу)
├─ test.html                  діагностика рівня (поки окремо, на старому коді)
├─ engine/
│   ├─ engine.js              рушій без інтерфейсу: прогрес, перевірка відповідей і описок,
│   │                         рівні 🌱🌿🌳, інтервали повторень, підбір завдань, помилки
│   ├─ math.js                генератори завдань з математики (E.GEN), щоразу нові числа
│   ├─ speech.js              озвучка: SAY.say (англ.), SAY.uk (укр.)
│   ├─ ui.js                  екрани: кабінет, кроки уроку, сесія з циклом помилок, звіт татові
│   └─ style.css
├─ content/subjects.json      діти (Аня, Артем), їхні предмети (open: true — доступний), денна норма завдань
├─ content/algebra/           алгебра 7 кл. Ані (генерується tools/gen_algebra.js; генератори — engine/algebra.js; diag.json — перевірка рівня)
├─ content/math2/             математика 2 кл. (генерується tools/gen_math.js; уроки m1–m10, навички skills/math.json)
├─ content/english/
│   ├─ path.json              етапи й уроки (урок з полем file — доступний)
│   ├─ lessons/l1.json        урок: правило, приклади, слова, які навички, план тесту
│   └─ skills/ps.json         мікронавички: назва, rule, worked (розібраний приклад), alt, банк items
├─ functions/api/[[path]].js  сервер (Cloudflare Pages Functions): вхід, прогрес, звіт у Telegram
├─ tools/                     генератори змісту, перевірки, тести (tools/README.md)
├─ ARCHITECTURE.md
└─ STATUS.md
```

**Підлаштування за перевіркою рівня:** у test.html кожне питання має `ls` — уроки, до яких воно належить. Після тесту урок отримує `lessons.X.skip = true`, якщо всі його питання розв'язані правильно без підказки (`diag.skip`). Пропущений урок не блокує наступні й не потрапляє в «Продовжити»; його навички ставляться в 🌿 з повторенням завтра (`applyPlacement`).

**Відкриття уроків:** урок відкривається після тесту попереднього; закритий урок можна відкрити раніше (`lessons.X.early`), якщо в школі вже ця тема. `strict: true` у завданні — описки не прощаються (правопис і є правилом, напр. -ing). `end: "?"` у завданні «склади речення» — знак у кінці. `apos: true` — апостроф важливий (Tom's ≠ Toms), перевірка через `E.normA`.

**Формат завдання** (`items` у skills/*.json): `type` (`choice` | `input` | `order` | `dict` — послухай і напиши | `fix` — знайди слово з помилкою, `bad` — його номер з 0, `a` — виправлене речення), `p` (умова, `___` — пропуск), `a` (відповідь; для input/order — масив допустимих варіантів), `o` (варіанти для choice), `words` (для order), `h` (підказки: натяк → ближче), `e` (пояснення правила), `err` (типові помилки → пояснення саме цієї помилки). Третя підказка — `rule` навички.

**Кілька предметів:** у ui.js `SUBS` — опис предмета (`base` — папка змісту, `words`/`diag` — чи є слова й перевірка рівня, `kid` — великі кнопки для молодших). `E.curSub` — поточний предмет; навички мають `subject`; план дня (`plans[предмет]`), повторення тижня (`wrs[предмет]`), помилки (`sub`) і лічильник дня — окремо для кожного предмета. Урок може задати свої кроки (`steps: ["explain","practice","test"]`). Звертання за статтю дитини: `g: "m"/"f"` у subjects.json, у ui.js `G("зрозуміла","зрозумів")`.

**Генератори (математика):** навичка замість `items` має `gen: "add20"` → `E.GEN.add20()` у engine/math.js повертає нове завдання (`type: "num"` з клавіатурою або `choice`, `p` з `___`, `a`, `h`, `e`, `err`, `pic` — картинка, `read` — текст для озвучки, `long` — задача, `calc` — вираз для автоперевірки, `steps` — задача по діях: `[{q, a, how}]`, кожна дія вводиться окремо, остання = відповідь). Згенеровані завдання, що потрапили в помилки, зберігаються цілком (`mistakes[].it`). Перевірка: `node tools/check_math.js` — 3000 прикладів на навичку.

**Алгебра (з 19.11.2026):** `engine/algebra.js` — генератори (E.GEN.fAdd, eLin2, pwProp…). Числові завдання `type:"num", kb:"alg"`: клавіатура 1–9, 0, «−», «,», «/»; `E.check` порівнює за значенням через `E.ratOf` (десятковий/звичайний дріб точно), нескорочений дріб → `typo` з повідомленням «скороти» (одна спроба без штрафу); `err` теж звіряється за значенням. Вирази (подібні доданки, дужки, одночлени) — `choice` з хибними варіантами з типових помилок. `chk` у кожному завданні — дані для незалежної перевірки `tools/check_algebra.js`. **Перевірка рівня в рушії** (`SUBS.algebra.diag = "inline"`): `diag.json` {items:[{skill,t}]}, екран `renderDiag/diagResult` в ui.js; хід — localStorage `school-diag:<дитина>:<предмет>`; результат `profiles.X.diagS[предмет] = {v,t,d,date,pct,skip,by,bad}` (злиття — новіший `t`), уроки з усіма навичками «правильно без підказки» → `lessons.X.skip` + `applyPlacement`. Озвучка «🔊 Послухати» після відповіді — лише в предметах зі словами (англійська). **Підсумкова перевірка етапу** (`SUBS.X.check = true`, зараз алгебра): `renderCheck/checkResult/runFix` в ui.js; завдання — з навичок уроків етапу; хід — localStorage `school-check:<дитина>:<предмет>:<n етапу>`; результат `profiles.X.checks[предмет][n] = {t,d,date,score,max,weak,best,rn,due,rt}` (злиття — новіший `t`); повторна перевірка (6 завдань) — коли `due` ≤ сьогодні, інтервали `RE_DAYS` = 14/30/60 днів; `showTask` має `cfg.noHint` і `cfg.calm`.

**Хостинг і сервер (з 16.11.2026):** сайт на Cloudflare Pages — https://school.akdtv.pp.ua (проєкт `school`, адреса-запаска school-9ax.pages.dev), оновлюється сам після коміту в `main`. Сервер — `functions/api/[[path]].js` (Pages Functions): `status`, `login` (PIN 4 цифри, хеш у KV; перший вхід задає PIN; 5 помилок → блок 15 хв), `progress` GET/PUT (прогрес дитини; PUT з `base` — якщо інший пристрій зберіг новіше, 409 і віддається його версія), `report` (звіт у Telegram), `ping`. Сховище KV `school-progress` прив'язане як `DB`; секрет `TG_TOKEN` у Settings → Variables and Secrets; звіти йдуть у групу «Домашня школа» (номер у коді, `TG_CHAT` може його перевизначити). Скинути PIN дитини: Workers KV → school-progress → видалити ключ `pin:<дитина>`.
**Синхронізація:** `engine/sync.js`. Вхід за PIN на кожному пристрої один раз (токен у localStorage `school-tok-<дитина>`). При вході й поверненні до вкладки — забрати з сервера й **злити** з тим, що є на пристрої (`E.mergeProfile`: дні, зірки, помилки, слова, уроки — об'єднання/максимум, нічого не губиться); `E.save` ставить `dirty` і відправляє з затримкою 2,5 с (окремо для кожної дитини); при закритті/ховані вкладки — одразу (fetch keepalive); конфлікт 409 → злиття й повторна відправка. Сервер: перевірка формату прогресу, ліміт 400 КБ, ≤30 звітів у Telegram на день від дитини. Тести: `tools/devserver.mjs` (локальний сервер з мок-KV, порт 8766) + `tools/e2e_sync2.py`. Без інтернету все працює локально («Продовжити без входу»). Старий сайт на github.io ходить на сервер нового домену (CORS), щоб перенести прогрес, і показує «Сайт переїхав». Локальна перевірка без сервера — порт 8765 (там синхронізація вимкнена).

**Вхід:** «Хто сьогодні вчиться?» → PIN → «Мої предмети» (усі предмети класу; недоступні — «Скоро») → кабінет предмета з кнопкою «Продовжити» і статусом дня. Без паролів.

**Прогрес** (localStorage, ключ `school-v3`): `{v:3, cur, profiles:{anya:{name, days, daily, skills, lessons, seen, mistakes, reports, diag}, artem:{…}}}`. `daily[дата][предмет]` — скільки завдань зроблено (норма — `dailyGoal` у subjects.json). `diag` — результат перевірки рівня. Перевірка рівня (test.html) зберігає хід окремо для кожної дитини. Зі старих версій переноситься лише прогрес з ім'ям Аня; тестові проходи тата скидаються. Цей самий об'єкт піде в синхронізацію.

**Як рахуються рівні:** 🌿 Знаю — 3 правильні поспіль без підказок (підказка обнуляє серію). 🌳 Засвоєно — правильно без підказки в день повторення (не в той, коли стала «Знаю»). Помилка: 🌳 → 🌿, повторення переноситься на завтра. Інтервали: 1 → 3 → 7 → 14 → 30 днів.

**Описка:** різниця в 1 літеру (або переставлені сусідні), не в останніх 2 літерах слова (там граматичні помилки: watchs, gos). Перша описка — «Майже, перевір написання», без штрафу. У диктанті описка в будь-якому слові, крім тих, що змінюються в типових помилках (`err`). Друга описка зараховується як з підказкою (пів бала) з показом правильного написання.

**Заняття на сьогодні:** план дня `profiles.X.plan = {d, warm, lesson, mist}`. Розминка — 5 завдань: спершу навички, яким настав день повторення, далі давно не бачені з почате (сьогоднішні — в кінець); помилки в розминці потрапляють у «Мої помилки». Частина без завдань зараховується сама. Правильна відповідь на будь-яке завдання прибирає його з «Моїх помилок».

**Мотивація (у профілі):** `stars` — журнал нарахувань ⭐ `{d, n, why}`, тиждень з понеділка; `reward` — `{text, goal, pin}` (PIN тата на зміну); `rewardWeeks` — тижні, коли нагороду зібрано; `badges` — `{id: дата}`, перелік і умови в `E.BADGES`; `cnt` — лічильники (daysDone, brave, back, rewards); `theme`. Серія: один пропущений день на тиждень (пн–нд) покривається ❄️ заморозкою, якщо дні до і після — навчальні.

**Повторення тижня:** `profiles.X.wr = {w (понеділок тижня), done, score, max, by}` + історія `wrHist`. Завдання — `E.reviewItems(12)`: по одному з кожної початої навички (lvl ≥ 1 або були спроби), найдавніші першими, далі ще коло; перемішано. На вихідних додається частиною в «Заняття на сьогодні» (`plan.reviewPart / plan.review`). +5 ⭐ раз на тиждень.

**⚡ Блискавка (math2):** `renderBlitz/blitzRun` в ui.js. Пул — `E.BLITZ` ∩ навички з n>0 або lvl≥1 (`E.blitzSkills`, якщо порожньо — m.add10/m.miss10); беруться лише прості `num`-приклади з `___`. 60 с, ✓/Enter, помилка → `E.addMistake`, правильна → `E.fixMistake`, `E.tick` на кожну відповідь; `E.record` не викликається (поспіх не має знижувати рівні). Дані: `profiles.X.blitz = {best, bestD, hist:[{t,d,ok,n}] (≤60)}`, злиття — максимум рекорду + об'єднання історії за `t`. +2 ⭐ за новий рекорд (не за першу спробу).

**🦖 Маскот (math2):** `engine/dino.js` — `DINO.FORMS` (вилуплення — 1 урок, далі пороги навичок 🌳 lvl≥3 предмета; форма не зменшується), `DINO.ITEMS` (речі: slot, поріг зірок за весь час `E.starsTotal`), `DINO.COLORS`, `DINO.svg({form,color,wear,size})`. В ui.js: `dinoCard/dinoNews/renderDino`. Дані: `profiles.X.dino = {name, color, wear:{slot:id}, form, items (скільки вже показано — для тостів «підріс»/«нова річ»), u (час зміни), v (2 — правила від 17.11.2026)}`; злиття — новіший `u`, `form`/`items` — максимум; за різних `v` береться новіша версія правил цілком.

**↺ Скидання етапу (батьки):** `E.resetIds(lessonIds, skillIds)` — видаляє уроки/навички, пише `profiles.X.resets[id] = Date.now()`; `E.sk/E.lesson` створюють записи з `g = resets[id]`; `mergeProfile` спершу об'єднує `resets` (максимум), потім відкидає з обох боків записи з `g < resets[id]`. Навички етапу — усі id з `E.SK`, що згадуються в JSON його уроків.

**Слова:** набори в `content/english/words/sets.json` (`{sets:[{id,title,ic,words:[[en,ua]]}]}`), слова уроків теж додаються в словник. Прогрес `profiles.X.words[en] = {box 1–5, due, n, ok, bad}`: правильно → коробка вище (інтервали 1/2/4/8/16, далі 30 днів), помилка → коробка 1 і ще раз наприкінці сесії. Режим: коробка ≤1 — картка, 2–3 — напиши англійською, 4+ — на слух або напиши. Сесія: до 10 слів, яким пора, + до 5 нових з поточної теми (`wset`), разом до 12. «Вивчено» — коробка 4+.
