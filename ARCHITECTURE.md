# Архітектура: домашня навчальна платформа (перший модуль — англійська для Ані, 7 клас)

> Мета: закрити прогалини з 5–6 класу, вийти на рівень 7 класу і йти далі.
> Головний принцип: **зрозуміло і цікаво, а не каторга.** Помилка — це сигнал «закріпимо ще разок», а не покарання.

Сайт: https://kadetovanton.github.io/school/ (GitHub Pages, репозиторій `KadetovAnton/school`)
Пристрої учня: iPhone (Safari) і MacBook Pro 2015 (macOS Monterey, Safari 15–16). Усе має працювати на обох.

---

## 0. Бачення: платформа для обох дітей і різних предметів

- **Діти:** Аня (7 клас) і Артем (2 клас). У кожного свій профіль: клас, прогрес, інтереси, нагороди, свій «вигляд» (Аня — кабінет підлітка, Артем — яскравий ігровий світ: коротко 5–10 хв, озвучені завдання, картинки, перетягування, спочатку з татом поруч).
- **Мета:** не зубріння, а розуміння і цікавість; показати, навіщо кожен предмет і як подивитися на світ з його точки зору.
- **Спільне ядро:** рушій, мотивація (зірки, значки, серії, нагороди), звіти для тата.
- **Два типи предметних модулів:**
  1. **Предмети-навички** (англійська, техніка математики/алгебри, правопис): практика до засвоєння, цикл «помилка → 2–3 схожі завдання», повторення (розділи 2–6).
  2. **Предмети-розуміння** (фізика, хімія, біологія, географія; для Артема — «Я досліджую світ»): формат «від явища до закону»: загадка з життя → «як думаєш?» → інтерактивна модель → пояснення простими словами → формула як короткий запис → «де це в житті» → досвід удома → перевірка розуміння («поясни, що буде, якщо…»).
- **«Навіщо цей предмет»:** коротка вступна серія на початку кожного предмета.
- **Порядок:** 1) англійська для Ані (доводимо рушій); 2) пілот предмета для Артема (з того, що найважче; уточнити в тата, а також його інтереси); 3) розширення.

## 1. Принципи (на чому стоїть система)

Взято з перевірених практик (Khan Academy, Duolingo, дослідження когнітивної науки про навчання):

1. **Навчання до засвоєння.** Не йдемо далі, поки навичка не засвоєна (Khan Academy).
2. **Пригадування замість перечитування.** Учень сам згадує й пише відповідь, а не впізнає готову.
3. **Інтервальні повторення.** Тема повертається через 1 → 3 → 7 → 14 днів.
4. **Перемішування тем.** У розминці навички змішані, щоб вчитися їх розрізняти (Simple чи Continuous?).
5. **Помилки повертаються наприкінці сесії**, а не одразу ж тим самим питанням (Duolingo).
6. **Розібрані приклади.** Спершу «дивись, як я думаю», потім сама.
7. **Короткі сесії.** Ціль 15 хвилин на день, краще щодня потроху.

## 2. Зміст: карта мікронавичок

Кожна тема ділиться на дрібні **мікронавички**. Помилка завжди прив'язана до конкретної навички, тож видно точно, де дірка.

Приклад, Present Simple:
| id | Мікронавичка |
|---|---|
| ps.base | I / you / we / they: дієслово без змін |
| ps.s | he / she / it: + s |
| ps.es | -s, -sh, -ch, -x, -o → + es |
| ps.ies | приголосна + y → ies (study → studies) |
| ps.has | have → has |
| ps.adv | місце always / usually / never |
| ps.neg | don't / doesn't + дієслово |
| ps.q | питання з Do / Does |

Кожна мікронавичка має:
- **пояснення** (коротко, українською, з прикладом і озвучкою);
- **розібраний приклад** («дивись, як я думаю», крок за кроком);
- **альтернативне пояснення**, тільки для складних навичок (-es/-ies, do/does, was/were, Present Perfect…);
- **банк завдань**: 8–15 різних речень у різних форматах;
- **типові помилки** з поясненням саме цієї помилки (`goed → went`, `studys → studies`).

### Шлях навчання (етапи)
1. **Фундамент:** Present Simple (2 уроки) → Present Continuous → Simple чи Continuous
2. **Опис світу:** There is / are → some / any, множина
3. **Минуле:** Past Simple (-ed) → 30 неправильних дієслів → питання й заперечення
4. **Порівняння і правила:** ступені порівняння → must / can / mustn't
5. **7 клас:** Past Continuous → Present Perfect → далі за підручником

Порядок тем 7 класу та словник підлаштовуються під шкільний підручник (коли буде фото змісту).

## 3. Формати завдань

| Формат | Для чого | Частка |
|---|---|---|
| Вписати слово | основна практика: пригадування | висока |
| Скласти речення зі слів | порядок слів | середня |
| Диктант: чую → пишу | слух + правопис (озвучка браузера) | середня |
| Знайди помилку в реченні | розуміння правила | середня |
| Вибір із 2–3 варіантів | лише знайомство з новою темою | низька |
| Читання тексту + питання | розуміння тексту | у кінці теми |
| Картки слів | словник | щодня |

**Перевірка відповідей:**
- без різниці великі/малі літери, апострофи, крапки, зайві пробіли;
- кілька правильних варіантів (`don't like` = `do not like`);
- **описка ≠ граматична помилка:** якщо різниця в 1 літеру і це не відома типова помилка, показуємо «майже, перевір написання» і даємо виправити один раз без штрафу.

## 4. Цикл «помилка → розуміння» (ядро системи)

```
Завдання
  ├─ правильно (без підказки) → навичка +1
  └─ помилка
       1. Пояснення саме цієї помилки (не просто «неправильно»)
       2. Розібраний приклад: «дивись, як я думаю»
       3. Серія закріплення: 2–3 НОВІ речення на ту саму навичку,
          з кожним разом підказок менше
            ├─ 2 з 3 правильно → «Зрозуміла! 💪» → далі
            └─ ні → альтернативне пояснення (інша аналогія/схема) → ще серія
                    └─ знову ні → позначка «розібрати з татом / репетитором»,
                       йдемо далі (не мучимо)
  Наприкінці сесії: ще раз 1 завдання на кожну навичку, де була помилка.
```

Мова інтерфейсу м'яка: «Закріпимо ще разок», «Майже!», «Розберімо разом», без «Помилка!», «Неправильно!».

Підказки (2–3 рівні): натяк → правило → (відповідь показуємо лише після спроби або «Не знаю»).
Підказка не карається сильно: правильно з підказкою = 0,5 бала.

## 5. Рівні засвоєння

| Для Ані | Внутрішньо | Як потрапити |
|---|---|---|
| 🌱 Вчу | не почато / спробувала | почала навичку |
| 🌿 Знаю | впевнено | 3 правильно поспіль без підказок |
| 🌳 Засвоєно | засвоєно | правильно при повторенні **в інший день** |

Засвоєна навичка може повернутися в «Знаю», якщо при повторенні помилка. Це нормально і не звучить як невдача.

## 6. Повторення

- **Розклад:** після «Знаю» навичка повертається через 1 → 3 → 7 → 14 днів. Помилка → інтервал скидається на 1 день.
- **Щоденна «Розминка» (5 хв):** перемішані завдання з навичок, яким пора повторитися, плюс 5–10 карток слів.
- **«Мої помилки»:** колекція речень, де помилялась. Можна пройти окремо.
- **Контрольна точка** після кожного етапу: коротка повторна діагностика, щоб бачити ріст у відсотках.

### Трек слів (окремо від граматики)
Картки за системою коробок: знаю → коробка вище → повертається рідше; не знаю → коробка 1 → завтра знову.
Слова за темами (розпорядок дня, школа, сім'я, їжа, хобі, місто, подорожі…), потім за підручником.
Формати: англ → укр, укр → англ (вписати), слухаю → пишу.

## 7. Цікаво, а не каторга (мотивація)

**Що робимо:**
1. **Короткий, зрозумілий день.** На головній одна велика кнопка «Заняття на сьогодні (~15 хв)»: розминка → новий крок уроку → помилки. Не треба думати, що робити.
2. **Видимий прогрес.** Мапа шляху з етапами, зірки за уроки, рівні 🌱🌿🌳, відсотки на контрольних точках. Дитина бачить, що росте.
3. **Серія днів з поблажкою.** 🔥 днів поспіль; 1 «заморозка» на тиждень, тож пропущений день не обнуляє все.
4. **Досягнення (значки):** «Перший урок», «7 днів поспіль», «10 помилок виправлено», «Майстер -es», «100 слів» тощо. Значки й за старанність, а не лише за ідеальність.
5. **Тижнева нагорода в реальному житті.** Зірки за тиждень → нагорода, про яку домовляються тато й Аня (заздалегідь, видно на сторінці: «до нагороди ще 12 ⭐»).
6. **Персоналізація.** Речення в завданнях про те, що їй цікаво (тварини, музика, друзі тощо, уточнити в Ані), з її ім'ям. Розблоковувані теми оформлення й аватарки за зірки.
7. **Міні-ігри для різноманітності:** «Знайди помилку», «Пари слів на час», «Збери речення», «Диктант-челендж». Раз на кілька днів «скарбничка-сюрприз» з бонусним завданням.
8. **Святкуємо зусилля:** «Ти виправила 5 помилок — це і є навчання!» Анімація-конфеті на кінець уроку.
9. **Вибір.** Після обов'язкової розминки можна обрати, що робити далі: урок, гра, слова.
10. **Вільний режим шкільних тем.** Якщо в школі контрольна з теми, яка за планом ще закрита, її можна відкрити. Замки для порядку, не як перешкода.

**Чого НЕ робимо:**
- «життів», які закінчуються через помилки (як сердечка в Duolingo): помилка ніколи не блокує навчання;
- рейтингів і порівняння з іншими;
- нагадувань із почуттям провини;
- довгих уроків: один крок ≤ 10 хв;
- реклами, сторонніх посилань, збору особистих даних.

## 8. Звіти

- **Для Ані:** «Мій прогрес»: рівні навичок, значки, серія, зірки.
- **Для тата (щотижня або після уроку):** кнопка «Надіслати татові» копіює текст: що пройдено, які навички западають, помилки, хвилин за тиждень. Пізніше можлива автоматична відправка в Telegram-бот.
- **Для репетитора:** короткий список навичок, які западають (та сама кнопка, коротша версія).

## 9. Технічна архітектура

```
school/
├─ index.html              вибір профілю → кабінет дитини
├─ test.html               діагностика рівня
├─ engine/
│   ├─ engine.js           рушій: цикл помилок, рівні, повторення, перевірка відповідей
│   ├─ ui.js               екрани, анімації, озвучка
│   └─ style.css
├─ content/                (по предметах: content/english/, content/world/ …)
│   ├─ path.json           етапи й порядок уроків
│   ├─ skills/ps.json      мікронавички теми: пояснення, приклади, банк завдань, типові помилки
│   ├─ skills/pc.json …
│   └─ words/daily.json …  набори слів
├─ ARCHITECTURE.md
└─ STATUS.md
```

- **Рушій один, зміст окремо.** Нова тема = новий JSON у `content/`, рушій не чіпаємо.
- **Статичний сайт:** без сервера, без бази, без паролів. Заборона індексації пошуковиками.
- **Прогрес:** у браузері (localStorage) з обгорткою на випадок помилок.
- **Синхронізація iPhone ↔ MacBook:** найпростіший безкоштовний сервер (наприклад, Cloudflare Worker + KV), де за секретним кодом зберігаються лише прогрес, зірки й значки, без імен і особистих даних. Закладаємо у формат прогресу одразу, підключаємо окремим кроком.
- **Сумісність:** старий Safari на macOS Monterey, тож без найновіших можливостей JS/CSS. Перевіряти на мобільному розмірі.
- **Озвучка:** вбудована в браузер (speechSynthesis, en-GB). Без сторонніх сервісів.
- **ШІ-чат на сторінці:** не зараз. Пояснення й підказки заздалегідь вбудовані в зміст. Живий помічник можливий пізніше через API з окремим ключем і запобіжниками для неповнолітніх.

## 10. Якість змісту

- Кожну нову тему перед публікацією перевіряю окремим проходом (правильність відповідей, однозначність завдань, рівень складності для 7 класу).
- На кожному завданні кнопка «Тут, здається, помилка»: потрапляє у звіт для тата → виправляємо.
- Свої матеріали, без копіювання текстів з підручників і чужих ресурсів.
